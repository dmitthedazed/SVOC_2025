# Contributing

This is the code and paper for a finished study, so changes are mostly fixes.

- **Found a mistake** in the code, numbers or paper? Open an issue and say where.
- **Sending a fix:** keep it to one thing. If your change affects the results, rerun `python analysis.py` and commit the regenerated figures with it.
- **Building on this work:** fork it, and cite it using the BibTeX in the README.
